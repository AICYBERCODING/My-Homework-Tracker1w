# 🎮 My Homework Tracker

A gamified homework tracker built as a Google Apps Script web app.

## Features

- 📘 Track homework scores week by week
- ⚡ Practice tests (multiple choice, auto-marked)
- 🧠 Mistake log with review mode
- ✍️ Writing review with AI marking
- 🏅 Levels, XP, streaks and achievements
- 📊 Progress charts and report cards
- 🛠️ Admin panel for user management

## Built with

- Google Apps Script
- Google Sheets (per-user data storage)
- Vanilla HTML, CSS & JavaScript
- Deployed as a Google web app
